# Gokul-Neha

A personalized wedding invitation web application for Gokul & Neha.

## Features
- Interactive Wedding Invitation UI
- Live Countdown Timer to Muhurtham
- Single Centered Wedding Ceremony event card
- Audio Background Music player (Autoplay, Loop, 30% volume)
- Google Maps Venue navigation (`https://maps.app.goo.gl/47n3xqSL9JYbfgEb9`)
- Responsive Arch-framed Couple portraits

## Tech Stack
- React
- Vite
- Tailwind CSS
- Lucide Icons
